# Infraestructura inicial

## Disponible

- Estructura de codi, proves, documentació i infraestructura.
- Format compartit amb `.editorconfig` i `.gitattributes`.
- Exclusions de dependències, fitxers generats i configuració local.
- Validació sense dependències externes amb Python.
- GitHub Actions en cada push i pull request, amb permisos de lectura.

## Decisions pendents

- Objectiu i funcionalitats de la primera versió.
- Llenguatge, framework i gestor de dependències.
- Base de dades i serveis externs, si són necessaris.
- Entorns, proveïdor de desplegament i gestió de secrets.

Aquesta base no crea recursos al núvol, no modifica usuaris ni configura credencials. L’usuari `developer` es manté sense canvis.
