# Contribuir

1. Crea una branca amb un nom descriptiu, per exemple `feat/initial-app`.
2. Mantén els canvis centrats en un objectiu.
3. Executa `python3 scripts/check_repo.py` abans de publicar-los.
4. Obre una pull request cap a `main` amb el propòsit del canvi i la validació feta.

Utilitza UTF-8, salts de línia LF i un salt de línia final. `.editorconfig` defineix el format compartit.

No afegeixis credencials, tokens, claus privades ni fitxers `.env` amb valors reals. Documenta els noms de les variables necessàries en un `.env.example` quan l’aplicació en necessiti.

Afegeix les proves i les comprovacions pròpies del llenguatge quan s’incorpori codi d’aplicació. La comprovació inicial del repositori no substitueix proves funcionals ni una eina de detecció de secrets.
